## Security Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                    DEFENSE IN DEPTH                             │
│                                                                  │
│  Layer 1: Network Perimeter                                    │
│  ┌────────────────────────────────────────────────────────┐   │
│  │  nftables Firewall (Default Deny)                      │   │
│  │  ├─ Block all incoming (except established)            │   │
│  │  ├─ Block all outgoing (except allow-internet group)   │   │
│  │  └─ Log all rejected connections                       │   │
│  └────────────────────────────────────────────────────────┘   │
│                         │                                       │
│  Layer 2: Application Isolation                                │
│  ┌────────────────────────────────────────────────────────┐   │
│  │  Firejail Sandboxing                                    │   │
│  │  ├─ Seccomp filters                                     │   │
│  │  ├─ Namespace isolation                                 │   │
│  │  ├─ Capability dropping                                 │   │
│  │  └─ Filesystem restrictions                             │   │
│  └────────────────────────────────────────────────────────┘   │
│                         │                                       │
│  Layer 3: System Monitoring                                    │
│  ┌────────────────────────────────────────────────────────┐   │
│  │  Audit System                                           │   │
│  │  ├─ File access monitoring                              │   │
│  │  ├─ Privilege escalation detection                      │   │
│  │  ├─ Rootkit behavior detection                          │   │
│  │  └─ Real-time notifications                             │   │
│  └────────────────────────────────────────────────────────┘   │
│                         │                                       │
│  Layer 4: Kernel Hardening                                     │
│  ┌────────────────────────────────────────────────────────┐   │
│  │  Sysctl Parameters                                      │   │
│  │  ├─ ASLR, DEP, stack protection                         │   │
│  │  ├─ Restricted kernel pointers                          │   │
│  │  ├─ Disabled unprivileged BPF                           │   │
│  │  └─ Ptrace restrictions                                 │   │
│  └────────────────────────────────────────────────────────┘   │
│                         │                                       │
│  Layer 5: Data Protection                                      │
│  ┌────────────────────────────────────────────────────────┐   │
│  │  LUKS Encryption (Optional)                             │   │
│  │  ├─ AES-256-XTS cipher                                  │   │
│  │  ├─ SHA-512 hash                                        │   │
│  │  └─ Full disk encryption                                │   │
│  └────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```
